# Security Policy

## Supported Versions

| Version | Supported |
|---------|----------|
| Latest on `main` | ✅ |
| Older branches | ❌ |

## Reporting a Vulnerability

This is a client-side only application with no backend or user authentication. All data is stored locally in the user's browser via `localStorage`.

If you discover a security issue (e.g., XSS, dependency with a known CVE), please **do not** open a public issue.

Instead, email: **hello@discoverkw.ca** with:

- A description of the vulnerability
- Steps to reproduce
- Potential impact
- Any suggested fix (optional)

We will respond within **72 hours** and coordinate a fix before public disclosure.
